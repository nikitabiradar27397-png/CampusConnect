# CampusConnect — Smart Student Club and Event Management System

## Overview
CampusConnect is a web application designed to help students explore clubs, manage events, record attendance, and generate participation certificates.

## Technologies
- React.js
- Tailwind CSS
- Firebase Authentication
- React Router DOM
- QR code generation
- jsPDF

## Features
- User registration and login
- Protected routes
- Student dashboard
- Club and event management
- QR-based attendance
- Certificate generation

## Getting Started
1. Clone this repository.
2. Install the project dependencies using `npm install`.
3. Configure the required Firebase settings using environment variables.
4. Start the development server using the appropriate command defined in `package.json`.
